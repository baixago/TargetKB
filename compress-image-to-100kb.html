What Does 100KB Mean?

KB (kilobyte) is a measure of file size — how much storage space the image file takes up. It's different from an image's pixel dimensions: a photo can still look large and sharp on screen while having a small file size, if it's compressed well. Many government portals, job application sites, and exam forms cap uploads at a specific file size like 100KB, separate from any width/height requirement they may also have.

How TargetKB Compresses Your Image

  • Runs an adaptive quality search directly in your browser, testing JPEG quality levels to land as close as possible to 100KB without going over
  • Very large images are first scaled down to a maximum of 3200px on their longest side for faster processing, and further if the target still can't be reached
  • If your original image is already under 100KB, it's kept unchanged instead of being recompressed unnecessarily
  • Everything runs locally using the Canvas API — nothing is uploaded to a server

Tips for Better Quality at 100KB

  • Start with a clear, well-lit original photo
  • Crop out unnecessary background yourself before uploading — TargetKB compresses file size, it does not crop your image
  • If your source has transparency (PNG/WebP), note the output is JPEG, so transparent areas will get a white background
  • Always preview the downloaded result before submitting it anywhere important

Frequently Asked Questions

Can I compress a PNG or WebP image to 100KB?

Yes. TargetKB accepts JPG, PNG, and WebP as input. The compressed output is always saved as JPEG, since JPEG compresses more predictably to a target file size.

Will my compressed file be exactly 100KB?

Not exactly — TargetKB searches for the closest possible match without going over your 100KB target. JPEG quality doesn't map perfectly to an exact file size.

Does compressing to 100KB reduce my image's dimensions?

Only if your original image is very large. Very large images are first scaled down to a maximum of 3200px on their longest side for faster processing, and further if needed to reach your target. Smaller images keep their original dimensions.

Is my image uploaded to a server?

No. Compression runs entirely in your browser using the Canvas API — your image is never sent to a server.

My phone saves photos as HEIC — will that work?

Not directly — TargetKB accepts JPG, PNG, and WebP. If your phone saved a HEIC file, switch your camera to JPG format first or convert the file to JPG, then upload it here.
